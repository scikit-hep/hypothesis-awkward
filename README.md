[Awkward Array][awkward-array] represents deeply nested, variable-length, and
mixed-type data — the kind of irregular structure common in scientific datasets.
Its valid arrays therefore span a vast combinatorial space, and test data chosen
by developers or generated by AI covers only a small corner of it. The edge
cases that break code are often in the parts that no one wrote down. Predefined
samples also let an implementation be fitted to them: an AI coding agent, for
example, can return the expected outputs for those inputs without implementing
the behavior for others. Either way, the tests pass while the code is wrong.
Iterative development, whose cycles of refactoring and feature changes AI coding
agents now shorten, depends on tests that pass only when the code behaves as
expected.

_Property-based testing_ addresses both problems. Instead of asserting specific
outputs for predefined inputs, you assert properties that should hold for any
valid input and let the framework generate the inputs at run time, so no
implementation can be fitted to them. [Hypothesis] is a property-based testing
library for Python: its [_strategies_][hyp-st] are composable objects that
describe how to build test data, and when a test fails Hypothesis _shrinks_ it,
searching for a minimal sample that still triggers the failure.

This package, [hypothesis-awkward], brings property-based testing to Awkward
Array with a collection of strategies for generating Awkward Arrays. Its main
strategy, [`arrays()`][api-ref-arrays], generates nearly fully general Awkward
Arrays: called with no arguments, it produces nested, variable-length, record,
and union layouts; leaf values of any NumPy dtype Awkward Array supports, as
well as strings and bytestrings; optional, masked, and missing values; and
virtual arrays — with options to constrain any of these. With this generality,
these strategies can surface edge cases in tools that use Awkward Array, and in
Awkward Array itself. Tests written with these strategies run in Awkward Array's
continuous integration (CI). Together with this package's own tests, they have
found bugs in Awkward Array, PyArrow, and Hypothesis; the [bugs-found
log][bugs-found] lists them.

## Installation

You can install the package from PyPI using pip:

```bash
pip install hypothesis-awkward
```

This also installs Hypothesis and Awkward Array as dependencies unless they are
already installed.

## The strategy `arrays()`

The function `arrays()` is the main strategy. It generates Awkward Arrays with
many options to control the output arrays.

### Sample outputs of `arrays()`

To see sample outputs of `arrays()`, run a test such as the following with
`pytest -s`, which shows printed output:

```python
from hypothesis import given

import awkward as ak
import hypothesis_awkward.strategies as st_ak


@given(array=st_ak.constructors.arrays())
def test_array(array: ak.Array) -> None:
    print(f'{array=!r}')
```

For example, this might print:

```python
array=<Array ['', '\U000c2f9f', ..., '@ú\x94j\U000c4364e'] type='4 * string'>
array=<Array [[], [], None, [], ..., [], [], None] type='42 * option[var * ?bytes]'>
array=<Array [??, ??, ??, ??, ??, ??] type='6 * var * unknown'>
array=<Array [NaT, NaT, ..., -9223372036854773681] type='26 * datetime64[Y]'>
```

missing values print as `None`. Virtual arrays print as `??`.
